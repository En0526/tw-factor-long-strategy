# 台股股價／財報因子做多策略（機器學習版）

> Y+30 top5% LightGBM · 收盤成交 · 等權 · ranking loss

以台股股價與財報因子為輸入，用樹模型（LightGBM, ranking）對每檔股票打分，於每個再平衡日買進分數最高的 **top 5%**，等權持有、到期再平衡，屬**純做多（long-only）**策略。

## 核心結果

- **主報 test 段外樣本 Sharpe ≈ 2.56**（test：2023-09-13 ～ 2026-06-16）
- 總評：**PASS**（淨報酬扣費後仍勝大盤，且勝率達門檻）

## 策略規格

| 項目 | 設定 |
| --- | --- |
| 預測目標 | Y+30（持有約 30 日 / 到下一個再平衡日） |
| 選股 | 分數 top 5% |
| 權重 | 等權 |
| 成交價 | 收盤（t 收盤已知 → t+1 收盤交易） |
| 模型 | LightGBM，ranking loss |
| 超參數 | lr = 0.2、num_leaves = 63 |
| 股票宇宙 | TSE + OTC（上市＋上櫃，不含興櫃／新上市） |
| 再平衡 | 到期再平衡（季報截止日：3/31、5/15、8/14、11/14 等；年報對應 Q4） |

## 樣本切分（時間平切三段）

- 全樣本：**2018-03-09 ～ 2026-06-16**
- **train**：～ 2020-12-10（選模型家族）
- **valid**：2020-12-10 ～ 2023-09-13（調 Y / top% / 學習率）
- **test**：2023-09-13 ～ 2026-06-16（最終外樣本評估，主報 Sharpe 2.56）

## 建模流程

1. **因子**：股價 + 財報因子（BP、EP、SP、CFP 等估值／品質因子）。
2. **模型選擇（train 段）**：比較多個模型家族，LightGBM 以 Sharpe 最高勝出；僅 LightGBM 走到 valid 調參。
3. **調參（valid 段）**：對 Y、top%、學習率等做網格探測，取 valid 表現最佳者。
4. **評估（test 段）**：鎖定規格後只在 test 段做一次外樣本評估。
5. **交易假設**：t 收盤產生訊號 → t+1 收盤成交，含交易成本，獲利滾入。

## 驗證與因子重要度

- **橫斷面檢定**：平均 IC、Newey–West t、Diebold–Mariano（DM）比較預測能力。
- **因子重要度**：以 TreeSHAP 做橫斷面解釋；估值類因子（BP 等）在多數分段權重居前，為核心驅動。
